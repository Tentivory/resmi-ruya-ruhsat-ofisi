# Resmi Rüya Ruhsat Ofisi

> Bu yazılım, 17 Eylül 2026 tarihinde yürürlüğe giren **Rüya Görme ve Gördüğünü Sanma Yönetmeliği** kapsamında hazırlanmıştır. Ruhsatsız rüya görmek kabahattir. Kabahat rüyada işlense bile sabah cezai işlem başlatılabilir.

## Bu daire ne yapar?

Vatandaşın gece göreceği rüyayı önceden tesciller. Onaylanmayan rüyalar sabah silinir. Ofis kâğıt kullanmaz; rüyalar zaten kâğıt değildir.

## Kurulum

Python 3 yeter. Başka bir şey istemez. İsterse de vermeyiz.

```bash
python3 ruya_ruhsat.py
```

## Kullanım

1. Giseye yaklaşın (yani terminali açın).
2. Adınızı söyleyin. Rüyadaki adınız da geçerlidir.
3. İstediğiniz rüyayı beyan edin.
4. Ruhsat numaranızı ezberleyin. Unutursanız zaten rüyanın tabiatı budur.

Yasaklı rüyalar listesi kodun içindedir. Listeyi ezberlemeyin; ezberlemek de rüyadır ve ruhsat ister.

## Sık sorulan resmi sorular

**Rüyamı başkasına devredebilir miyim?**  
Hayır. Rüya devri 2019'dan beri kapalıdır.

**Ruhsatımı kaybettim.**  
Kaybetmek de bir rüyadır. Yeni başvuru yapın.

**Neden bu kadar ciddi?**  
Çünkü ciddiyet rüyada bile resmi evraktır.
